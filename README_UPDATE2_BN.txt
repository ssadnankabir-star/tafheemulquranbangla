আপডেট ২: অটো-আপডেট + "নতুন আপডেট এসেছে" নোটিশ + ইনস্টল পপআপ
=========================================================

ফাইল (শুধু ২টা, দুটোই আগেরটা বদলে — public/ ফোল্ডারের ভেতরে):
- public/index.html
- public/sw.js

আগে আপনার রিপোতে আগের আপডেট (Kalpurush + তাজউইদ) পুশ করা থাকতে হবে, কারণ এই দুই ফাইল ওটার ওপরেই বানানো।

GitHub-এ কীভাবে দেবেন (ফোন বা কম্পিউটারের ব্রাউজার থেকে)
1) রিপো খুলুন → public ফোল্ডারে ঢুকুন।
2) Add file → Upload files → index.html ও sw.js বাছুন (একই নামে থাকলে বদলে যাবে)।
3) Commit changes চাপুন। Vercel নিজেই ডিপ্লয় করবে।

কম্পিউটারে git থাকলে:
  কপি করুন: public/index.html, public/sw.js  →  রিপোর public/ এ
  git add public/index.html public/sw.js && git commit -m "auto update + install popup" && git push

কী কী যোগ হয়েছে
1) ইনস্টল পপআপ: লিংকে ঢুকলে কার্ড আসে — "আল কুরআন অ্যাপ ইনস্টল করুন [ইনস্টল] [×]" (নিচে, বটম বারের ওপরে)।
   - Android Chrome: ইনস্টল চাপলে সরাসরি ইনস্টল প্রম্পট।
   - iPhone Safari: Share → Add to Home Screen লেখা কার্ড।
   - Facebook/Messenger ইত্যাদির ভেতরের ব্রাউজারে: "Chrome/Safari-তে খুলুন" লেখা কার্ড।
   - × চাপলে ৭ দিন আর আসবে না; ইনস্টল করা থাকলে বা অ্যাপ হিসেবে খুললে আসে না।
2) অটো-আপডেট: অ্যাপ খোলার সময়, ফোনে ফিরে আসার সময় এবং প্রতি ৩০ মিনিটে নতুন সংস্করণ খোঁজে।
   - আগের সেশনে নামানো আপডেট: অ্যাপ খুললেই নিজে থেকে প্রয়োগ হয়।
   - ব্যবহারের মাঝে আপডেট এলে উপরে কার্ড: "🔄 নতুন আপডেট এসেছে [আপডেট করুন]" — চাপলে একবার রিলোড হয়ে নতুন সংস্করণ।
   - আপডেটের পর "✓ অ্যাপ নতুন সংস্করণে আপডেট হয়েছে" বার্তা।
   - আর Clear data করতে হবে না।
3) পেজ খোলার সময় সবসময় আগে নতুন index.html আনার চেষ্টা (৩ সেকেন্ডের মধ্যে), অফলাইনে সেভ করা কপি।
4) ইনস্টলের পর সব ডাটা (~২৮ MB) এখন শুধু Wi-Fi তে (এবং ডাটা-সেভার বন্ধ থাকলে) নিজে নামে; মোবাইল ডাটায় নামে না — পড়া সূরাগুলো তবু অফলাইনে চলে।

একবারের জন্য মনে রাখুন
- যাদের ফোনে আগের সংস্করণ ইনস্টল করা, তারা এই আপডেট পাবে অ্যাপটা সম্পূর্ণ বন্ধ করে (রিসেন্ট থেকে সোয়াইপ করে) আবার খুললে। তারপর থেকে সব আপডেট স্বয়ংক্রিয়।
- নতুন সংস্করণ বের করার সময় public/sw.js ফাইলটা (অন্তত এক বাইট) বদলাতে হবে, নইলে "নতুন আপডেট এসেছে" কার্ড আসবে না (তবু পরের বার খুললে নতুন index.html আসবে)। আমি ফাইলে "build" নম্বর বদলে দিই।

পুশ নোটিফিকেশন (ফোনের নোটিফিকেশন বার) এতে নেই: ওটার জন্য আলাদা সার্ভার (Firebase Cloud Messaging/Web Push) ও ব্যবহারকারীর অনুমতি লাগে। চাইলে পরে আলাদা করে বানিয়ে দেব।
